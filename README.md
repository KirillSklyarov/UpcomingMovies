# Upcoming Movies

Приложение для просмотра информации о предстоящих фильмах с использованием API TMDb. Проект демонстрирует использование Clean Architecture, MVVM и Coordinator Pattern.

## Последние изменения

- Произведена оптимизации структуры приложения
- Расширен список типов ошибок и их локализованные описания
- Улучшена обработка сетевых ошибок с информативными алертами
- Улучшение пользовательского интерфейса и визуальных компонентов

## Основные функции

- Просмотр списка предстоящих фильмов
- Детальная информация о фильме
- Просмотр актерского состава и съемочной группы
- Отзывы и видео к фильмам
- Поиск фильмов
- Авторизация через TMDb
- Профиль пользователя
- Избранное и список ожидания
- Пользовательские коллекции фильмов
- Виджеты для быстрого доступа к фильмам

## Используемые технологии

- Swift 5
- UIKit
- MVVM, Coordinator Pattern
- Dependency Injection через Swinject
- Kingfisher для загрузки и кэширования изображений
- SwiftLint для поддержки стиля кода

## Требования

- iOS 13.0+
- Xcode 14.0+
- CocoaPods 1.9.0+

## Установка

1. Клонировать репозиторий
2. Выполнить `pod install` в корневой директории проекта
3. Открыть файл `.xcworkspace` и запустить проект
